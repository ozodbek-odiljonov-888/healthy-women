# Healthy Women — Security

This repository is a non-clinical preview. Do not store actual patient data.

Never commit names, surnames, contact information, period dates, symptoms, medical history, bot tokens, webhook secrets, signing keys, passwords or databases.

Use encrypted server-side secret storage for Telegram BOT_TOKEN and WEBHOOK_SECRET. Do not expose secrets in site JavaScript.

The bot preview does not enable personal health synchronization or reminders. Both require explicit informed consent, data controls, encryption and an independent review.

Android debug APK is for testing only. Never distribute as a clinically validated product.
